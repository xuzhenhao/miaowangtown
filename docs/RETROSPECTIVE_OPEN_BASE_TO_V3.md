# 复盘：开源底座 → Innerscene 调咩咩 v3（2026-10-28）

> 用户反馈：效果「惨不忍睹」，要求停下来复盘。  
> 本文件只做根因，不继续改码。

## 1. 一句话

**工程门（Rest / CC0 / 蒙皮 0 / 五印记可读）连续变绿，观感门（一眼像咩咩、HD-2D 细像素地板）从未过。**  
我们在错误的成功指标上迭代了三轮，把「清单可勾」误当成「可以交肉眼」。

## 2. 时间线（压缩）

| 阶段 | 结论 | 真正学到的 |
|---|---|---|
| BlenderKit RF | `--input` 通，walk 碎腿 HOLD | Remesh 毁 UV；迈步 Rest 否决动作库；RF≠可开放分发 |
| Grab3D CC0 | 许可+留 UV 更好，仍 HOLD | **mid-stride Rest 一票否决**；许可证好≠能用 |
| Innerscene 站姿 | Rest 关 PASS | 对称四足站立才是底座硬门槛 |
| 调咩咩 v1→v3 | 印记 4/5→5/5，耳骨从误绑尾改正，walk 略好 | 清单绿了，画面仍是色块猫+绿眼镜 |

## 3. 观感惨的根因（按杀伤力）

### R1 · 成功指标错位（最大）
- 勾的是：Rest 对称、skin seam/shear/belly=0、五印记「可读」、DNA 滑条有差。
- 用户要的是：3 秒内认出咩咩、细像素 HD-2D、干净平涂+真阴影，不是工程对照条。
- **后果**：每轮「CONDITIONAL PASS / 交肉眼」都在透支信任。

### R2 · 外观管线不匹配底座
- Innerscene 原材质是 **8 个纯色槽、无狸花贴图**；为喂 `coatBaker` 强行重排到 PART 图集 UV。
- `semanticMarkings` 烤出的是 **语义色块 blob**，在低模+像素化后变成碎斑/锯齿毛色，不是「照片精绘贴图」。
- 眼鼻用 **billboard/贴片** → 绿眼镜、漂点，直接毁脸。

### R3 · Path B 启发式绑骨太脆
- 耳骨用「最高点」→ 绑到尾巴；脸锚套生产母版尺度 → 漂在网格外。
- v2/v3 是在补启发式的洞，不是建立可复用的「开源底座 intake 规格」。

### R4 · 减面过狠 + 自动权重
- 10k 三角 + 自动权重软化，肩腹侧视永远偏「积木/折痕」。
- 清审计带 ≠ 观感平滑。

### R5 · 产品终局与本轮手段打架
- 终局（仍正确）：通用开源写实底座 + DNA，让用户调自家猫。
- 本轮手段：在 **没有好看静止外观** 之前，就上运行时语义印记 + DNA，等于用补丁画皮。

## 4. 应保留的结论（不要推倒重来时丢掉）

1. **Rest 必须对称四足站立**（Grab3D/BlenderKit 迈步路径关闭）。
2. **可开放底座要 CC0**（BlenderKit 仅内部对照）。
3. **跳 Voxel Remesh、保 UV** 方向对；Remesh 灰模不能当外观母版。
4. **先诊断再改**（耳=尾）有效；禁止再盲开 v4 色块精修。
5. 生产母版始终未覆盖 —— 这点做对了。

## 5. 应立刻停止的做法

- 再在 `innerscene_miemie_v*` 上堆 denser blobs / 又一轮「交肉眼」。
- 用五印记勾选表代替观感验收。
- 未定义「好看静止帧地板」前，就把隔离底座晋升生产。

## 6. 可选下一方向（需你拍板）

| 方案 | 核心逻辑 | 适合如果… |
|---|---|---|
