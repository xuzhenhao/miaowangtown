# 《喵汪小镇》零散真照片 → HD-2D 精致像素猫 实战经验与方法论手册

> **版本**：v1.0（基于 2026-10-28 `Route A v1 → v4 Clean` 静态观感破局实证沉淀）  
> **状态**：已获用户肉眼验收通过（「这次好很多了，点赞」，对应提交 `76a9bfb`）  
> **核心问题定义**：在不依赖「标准多视图教材级拍摄」、同时避开「写实 3D 恐怖谷效应」的前提下，如何把用户随手拍的几张猫咪日常杂照，稳定转化为 **HD-2D 小镇里既一眼认得出自家猫（五印记神还原）、又精致通透不糊不脏的像素猫**？

---

## 一、 顶层认知破局：三个必须锁死的硬前提

1. **输入端硬约束：猫不可能配合拍出「标准多视图站姿教材照」**
   - 任何默认用户能拍出「正前、正左、正右、正背四足对称站立」的摄影测量（Photogrammetry）或单图刚性重建方案，在实际落地时都会因猫咪乱动、视角缺失而崩盘。
   - **正确解法**：输入只能是「3～8 张日常随手拍杂照」，靠 **「家猫品种解剖先验 + 杂照特征提取（五印记/毛色/脸型） + AI 视角受控生成」** 补齐视角，而非硬拼照片网格。

2. **输出端硬约束：避开写实 3D 恐怖谷，终局画面必须是「HD-2D 精致细像素」**
   - 真照片直转写实 3D 极易陷入「塑料死眼珠、僵硬毛皮」的恐怖谷；而早期粗糙像素化又曾被误当作「掩盖不像的遮羞布」。
   - **正确解法**：3D 底座与骨骼只作为**中间驱动层**（玩家不可见），最终呈现给玩家的必须是 **具有自然毛流体积过渡、大眼高光通透、2×2 整数像素块对齐的 HD-2D 细像素图层**。

3. **造型比例硬前提：写实猫头身比缩成像素必糊，必须「微 Q 化（Chibi Proportion）」**
   - **惨痛教训（Innerscene v1–v3）**：写实家猫的头高仅占全身 20%～25%、眼窝窄小；一旦下采样到 ~100×100 像素网格，整张脸只剩十几颗泥巴色像素点，五官和嘴套彻底糊成一团。
   - **破局定式**：底座必须采用 **HD-2D 微 Q 头身比**——**头高占全身高约 40%～45%**、脸颊圆润饱满、杏仁大眼占脸宽近 1/3、耳朵挺立饱满、四肢圆润短实。只有先把五官面积放大，缩成像素后眼神与阴阳嘴套才能一眼抓人。

## 二、 路线演进与踩坑复盘（从 A/B 对比到 Route A v1 → v4）

| 阶段 | 核心做法 | 用户反馈 / 实测表现 | 暴露出的真根因 |
| :--- | :--- | :--- | :--- |
| **路线 B（程序精绘分层 UV）** | 用 Python 在 1024 UV 上按坐标公式画虎斑条纹、嘴套掩码与绿眼，再 2 档色阶平涂 | 线条虽锐利，但带有明显的「程序画图生硬感」，缺乏真猫绒毛的生命力 | 数学公式画出的条纹和色块过渡太机械，没有真猫毛发的高频层次与自然体积柔光 |
| **路线 A v1（AI 视角受控生成 + 3D 投影）** | 微 Q 底座导深度图 → AI 结合咩咩真照生成同视角图 → 反投 UV 下采样 | **用户首选认可左下角（路线 A）**：「感觉更好，有真猫毛发层次与柔光体积感」 | AI 原生生成的毛流与体积光影远胜程序画色块；但 v1 初版五印记不够突出，且经 3D 重复重采样后略软 |
| **路线 A v2（保频脚本调色 + Bilinear 92×92）** | 在 v1 上用脚本叠五印记色块，并用双线性插值（Bilinear）缩到 92×92 后非整数放大贴回小镇 | 用户反馈：「整体是那种感觉，但精度上没有左上角那种精致感，有种糊糊的感觉」 | ① **Bilinear 下采样**制造了大量半透明灰阶软边（相邻像素差 `<3` 高达 76.1%）；② **二次非整数缩放**（92→276→210）导致 2px 与 3px 像素块交错重影 |
| **路线 A v3（14 色强制量化 + 脚本硬画橙斑）** | 改用 14 色强制聚类吸附去糊，并用脚本椭圆公式在手腕/脸颊硬画橘斑、爪尖画黑线 | 用户截图直接打回（「你看这效果」） | ① **背景擦除漏掉原猫 4 只白爪**（脚下飘着 4 只鬼影残爪）+ 台阶 `x%6` 竖条拉伸；② **脚本硬画的橘色圆点与八字胡像劣质油漆膏药**；③ **14 色强制量化**把 AI 柔美毛流砍成了脏乱的迷彩碎斑；④ 右后腿缺失（仅 3 条腿） |
| **路线 A v4 Clean（纯正 AI 原生像素精绘 + 2×2 整数网格零损合成）** | 彻底重修干净空底板 + 废除一切脚本涂椭圆与 14 色量化 + AI 原生精绘五印记与四腿环纹尾 + `114×104` 逻辑网格按 `2×2` 整数块 1:1 贴入 | **用户验收点赞通过**（「这次好很多了，点赞」） | 保住了 AI 原生细腻的绒毛体积层次，同时靠「纯 Nearest + 2×2 整数像素块 1:1 对齐」实现了刀刻般干净的像素颗粒感 |

## 三、 五条黄金技术铁律（后续所有猫咪与动作落地的强制标准）

### 铁律 1：严禁用 Python 脚本画椭圆/几何色块冒充毛色印记
- **禁止行为**：永远不要用 `fillRect`、高斯椭圆公式、硬阈值掩码在贴图或精灵图上直接涂「橙色圆点」「八字胡色块」或「几何条纹」。任何代码硬涂的色块在像素化后都会像贴在猫身上的劣质油漆膏药。
- **标准做法**：所有毛色印记（如咩咩的右满左浅阴阳花生嘴套、胸前白围脖连左肋白云斑、腹缘暖橘过渡毛、前高后低四蹄白袜、深棕虎斑与环纹尾）必须由 **AI 受控生成（结合真照参考与目标 HD-2D 像素画风）原生长在毛流里**。

### 铁律 2：严禁使用强制低色数（如 14 色）全局量化破坏体积过渡
- **禁止行为**：不要为了追求「硬边像素感」去做全局 K-Means 或 14 色色板硬吸附——那会把猫脸和背部的自然球面柔光切成一块块脏乱的「迷彩碎斑」。
- **标准做法**：**「色彩层次丰富 + 采样边界锐利」才是高级 HD-2D 的精髓**。保留 AI 原生丰富的暖棕、焦糖、奶油白绒毛过渡色阶，靠 **纯点采样（Nearest-Neighbor）** 和 **干净的 1px 深褐外描边（`#1b100a`）** 来确立像素画的精致边界。

### 铁律 3：严格对齐 `2×2` 整数画布像素块，零二次非整数缩放（Texel Grid Parity）
- **定量基准**：在 `1364×1064` 级小镇标准画布中，石桥小人与目标猫的**单个逻辑像素块严格等于 `2×2` 画布像素**。
- **标准尺寸**：微 Q 猫在小镇画布中的净尺寸约为 **`228×208` 画布像素**，严格对应 **`114×104` 逻辑像素网格**。
- **合成铁律**：从 `114×104` 逻辑网格生成精灵后，只做一次 **`×2` 整数倍 Nearest 放大**，随后以 **1:1 整数坐标**直接贴入小镇底板；全程严禁任何 `Bilinear/Bicubic` 缩放或二次非整数 resize（如缩到 210px 高），从根源杜绝重影与软糊。

### 铁律 4：解剖完整性与眼神微结构必检清单
每一帧像素猫产物必须同时满足以下五项视觉微结构：
1. **四足完整分离**：左前、右前、左后、右后四条腿与四只白袜清晰独立，绝不允许后腿融合成一条（三脚猫）或悬空错位；爪尖分趾靠自然柔和的暗部像素收口，不戳生硬锯齿叉子线。
2. **尾巴环纹可读**：尾巴姿态自然舒展，深黑褐与暖金棕交替环纹清晰，绝不涂成一根死黑棒子。
3. **翠绿大眼高光**：深棕上眼睑弧线 + 深翠至亮翡翠绿通透虹膜 + 清晰竖瞳 + 左上角干净白高光点，眼神灵动聚焦。
4. **咩咩五印记自然融合**：① 右满左浅阴阳嘴套、② 胸腹雪白围脖连左肋白云、③ 腹缘自然暖橘毛色过渡、④ 前高后低四蹄白袜配后腿虎斑、⑤ 砖红粉小鼻头。
5. **接地阴影融合**：四只爪垫下方配柔和半透明深色椭圆接地阴影（Contact Shadow），与小镇石板地光影方向一致。

### 铁律 5：制作人必须执行「与用户同视野的 4x～8x 放大特写自审」
- **教训**：全屏缩略图（`1364×1064`）很容易掩盖脚下残影、背景修补条纹和局部涂鸦色块；用户一旦放大截图（如 `t676u`），所有瑕疵一览无余。
- **强制流程**：每次交付前，必须先生成一张 **猫部原图裁剪的 4x 放大特写图（Closeup Crop）** 并用 `Read` 逐块审视：
  - 查脚下石板地：是否有原图擦除不全的残爪鬼影或亮斑？
  - 查头顶与四周背景：是否有 `x % N` 取模拉伸条纹或抠图白边/黑刺？
  - 查猫体表面：是否有代码硬涂的圆点、色块断层或少腿断尾？
  - 任何一项不干净，内部直接打回重做，严禁半成品交到用户面前。

## 五、 下一步衔接路线（从「单帧静态过关」走向「小镇里活起来」）

既然单帧静态观感已由 **Route A v4** 确立为黄金标杆（Gold Standard），后续「让猫在小镇里走动、蹲坐、舔毛、打滚」的落地方案必须严格守护 v4 的画质，不走回头路：

1. **路线选择：以 `Route A v4` 为基准锁脸/锁外观，驱动多视角与动作序列**
   - **方案 1（3D 微 Q 骨骼驱动 + AI 多视角/关键帧受控一致化烘焙）**：用微 Q 3D 猫底座（`cat_chibi_base.glb` + 26 根四足骨骼）跑出准确的四拍猫科步态（walk）、呼吸蹲坐（idle/sit）、舔毛（groom）深度与姿态序列，结合 `Route A v4` 作为强外观锚点（Reference Anchor），烘焙出与 v4 完全同画质、零涂鸦色块的 `114×104`（2×2 像素块）八方向/动作精灵图集或全视角 UV。
   - **严守底线**：无论底层用实时 3D 离屏像素化还是离线烘焙序列帧，最终在小镇画布上呈现的每一帧，都必须保持 `Route A v4` 的 **AI 原生绒毛质感 + 2×2 整数像素网格对齐**，绝不再退回生硬程序色块或双线性软糊。
